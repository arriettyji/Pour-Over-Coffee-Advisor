# 实践观点资料库

本目录把实践者的操作方法、实际观察、机制解释与特定对象案例分别保存。它为运行时分析提供现实先验、可复现方法和待检验假设，不替代 `../theory/` 中的稳定知识。

实践库不以“像不像论文”作为统一质量标准。完整比赛配方的价值在于高约束方法案例，制造商页面的价值在于版本和结构事实，长期博客的价值在于反复观察与方法演化，访谈和历史文章的价值在于来源图谱。只有当某项资料被用来主张普遍因果或精确效应时，才要求与该主张相称的实验、对照和测量。

## 运行时使用规则

1. 先按当前咖啡、烘焙、豆龄、滤杯版本、滤纸、粉量、磨豆机/刀盘、水和目标筛选案例。
2. 特定咖啡或器具案例作为完整对象保留；只把共享条件明确的部分迁移到当前案例。
3. 将作者实测、作者感官观察、作者解释、品牌主张和 Skill 推断分开。
4. 比赛方案首先视为特定咖啡、舞台目标和服务流程下的案例，不因获奖而提高机制证据强度。
5. 同一观察在不同来源重复出现时记录重复条件；不同条件下的相反观察不强行合并。
6. 方法参数不能脱离原粉量、床深、滤纸阻力、磨豆机颗粒分布、水和烘焙状态直接复制。
7. 本目录出现的咖啡、滤杯、滤纸、磨豆机、水壶和其他器材全部标为外部案例对象。它们可以进入证据池、迁移分析或对象研究，不能仅凭出现在文章、比赛方案或器材案例中进入用户库存候选池。
8. 若外部案例器材也出现在用户当前请求或私人档案中，先按规范 `canonical_id` 分别记录“外部案例证据”和“当前可用性证据”，再让同一实体进入候选池；同品牌、同系列或相似名称不能替代这一步。

## 单项记录字段

每项深入记录至少包含作者/机构、日期与载体、原始位置、资料类型、对象与条件、该资料实际提供的内容、可支持的决策、迁移条件和边界。资料提供完整方法时记录全部参数；提供观察或机制时分开记录；提供产品或历史事实时保存版本和身份。不要为了统一格式，把没有做实验的资料伪装成实验，也不要因为它不是实验而忽略其本来能够承担的工作。

## 已知边界

- 汇编正文并非原始载体；关键决定优先回到记录的原始 URL 复核。
- 比赛方案来自用户提供的图片转录，部分缺少原始图片 URL、视频时间戳或可核对的完整演讲。
- 实践文章包含方法、长期经验、产品事实、单作者观察、对照测试和历史资料等不同类型；按其功能使用。需要普遍因果或定量结论时，再检查是否有相称的独立研究支持。
- 制造商页面同时承担说明和营销功能；可用来确认结构与官方建议，感官和机制主张维持实践证据等级。
- 2025–2026 的部分文章和器具仍很新，长期重复性与独立测试不足。
