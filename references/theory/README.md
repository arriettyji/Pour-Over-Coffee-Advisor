# 稳定理论知识库

四个主题文件均使用同一证据卡结构。卡片按决策问题组织，使运行时能够从“当前判断”回到原始来源、研究方法和适用边界。

这 49 张卡片构成第一版理论下限，并非封闭知识集合。运行时如有新研究影响关键决定，先按 `../evidence-policy.md` 评估，再在当前回答中引用；稳定、重复且具有迁移价值的结论才进入固定库。

## 证据强度

- `A`：多项直接研究、标准化方法或高质量系统综述方向一致，边界清楚。
- `B`：至少一项直接同行评议研究或权威技术专著支持，仍受样品/设备/方法限制。
- `C`：间接研究、模型推论、有限样品、技术专著中的原创观察或多项一致的专业资料。
- `D`：背景性解释、待验证假设或可用于生成下一轮试验的弱先验。

证据强度描述“这项结论在其限定条件内的支持程度”，不描述其听起来是否合理。

## 调用规则

1. 从当前决策反查卡片，而不是按领域顺序复述教材。
2. 引用卡片时保留限定条件；若当前对象超出研究对象、设备或范围，降低一档使用。
3. 机制模型支持变量关系；感官结论需要直接感官方法或明确标注为推断。
4. 标签型信息只形成先验，需由当前烘焙、流动、测量和感官证据更新。
5. 多张卡片共同支持一个决定时，记录各自贡献；任何单卡“单独不足以证明”的内容不得被组合文字掩盖。
